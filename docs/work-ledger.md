| Aug 13 | **Hardening pass: four attack surfaces closed, found by auditing our own limitations.** (1) *Retry masking* — a claimant's own earlier upload could hide a cross-policy match, because the near search returned one nearest record and the same-policy exemption ended the check; `findNearest` now takes `excludeRegistrant` in all three store backends, `/api/lookup` keeps the near search running even when an exact match exists, and the enclave judges the near match independently — four regression tests pin the behaviour. (2) *Parser isolation* — image decoding (the classic RCE surface) moved into a disposable child process spawned with a clean environment: no signing key, no registry URL, killed on a 10s deadline; an exploit in the decoder lands in a process that knows nothing.
